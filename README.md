# Ferretería Alcázar – PWA demo
```
npm install
npm run dev      # desarrollo
npm run build    # produce /dist
```
Deploy: subir a GitHub → Settings → Pages → Source: **GitHub Actions**. Cada push a `main` publica.
Pendiente de confirmar con el local: horarios (`src/data.js`), número de WhatsApp, precios, reseñas reales.
